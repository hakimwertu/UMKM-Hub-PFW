# UMKM-Hub-PFW 🏪

Aplikasi Manajemen UMKM dan Katalog Produk Digital berbasis Web yang dikembangkan menggunakan Framework Laravel 11. Proyek ini merupakan implementasi nyata untuk mata kuliah **Pemrograman Framework (PFW)** di Program Studi Sistem Informasi, **Politeknik Caltex Riau**.

## 📝 Tentang Proyek
Proyek ini dirancang untuk mendigitalisasi UMKM dengan memberikan platform bagi pemilik usaha untuk memamerkan produk mereka. Fokus utama pengembangan meliputi **Role-Based Access Control (RBAC)** dan manajemen data produk yang dinamis.

## 🚀 Fitur Utama
*   **Multi-Role Access**: Membedakan hak akses antara Admin dan Guest/Pemilik UMKM.
*   **Profil UMKM**: Setiap akun (Guest) dapat mengelola profil toko mereka sendiri.
*   **Katalog & Stok Produk**: Input produk UMKM disertai dengan manajemen stok (Indikator badge Success/Danger).
*   **Sistem Ulasan & Rating**: Pelanggan dapat memberikan feedback berupa komentar dan rating bintang pada setiap produk.
*   **Integrasi Kontak**: Fitur chat langsung ke penjual via WhatsApp API.
